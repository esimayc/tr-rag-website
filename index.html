About the Project

Building a more transparent and verifiable question-answering system for Turkish documents.

TR-RAG is a graduation research project focused on developing a Turkish question-answering assistant using Retrieval-Augmented Generation (RAG). Rather than relying solely on a language model's internal knowledge, the proposed system retrieves relevant information from documents before generating an answer.

The system aims to provide answers supported by identifiable source passages, allowing users to verify the information against the original documents. When the available evidence is insufficient, the assistant is designed to acknowledge this limitation instead of generating unsupported information.

A central focus of the research is Turkish language processing. By comparing different retrieval and generation configurations, the project will investigate how Turkish linguistic characteristics influence retrieval effectiveness, answer quality, and overall system reliability.

Document-grounded answers

Answers are generated using relevant passages retrieved from Turkish document collections.

Verifiable citations

Generated responses aim to include references that allow users to trace information back to its source.

Evidence-aware responses

The system is designed to recognize insufficient evidence and avoid unsupported answers.

Turkish-focused research

The project evaluates RAG methods with particular attention to the linguistic properties of Turkish.
