# TR-RAG

### Turkish Question Answering with Retrieval-Augmented Generation

TR-RAG is a Computer Engineering graduation project at TED University (2026–2027).

The project investigates Retrieval-Augmented Generation (RAG) techniques for Turkish document-based question answering, focusing on answer accuracy, source consistency, hallucination reduction, and response time.

## Research Focus
- Turkish language characteristics and morphology
- Document chunking strategies
- Turkish-capable embedding models
- Vector databases
- Hybrid retrieval (BM25 + semantic search)
- Re-ranking techniques
- Open-source language models
